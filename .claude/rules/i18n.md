# Rule card — i18n

> Distilled invariants for agents and `/review`. Authoritative narrative
> is `CLAUDE.md` (§Localisation). `CLAUDE.md` wins.

- Translations are Dart `Map<String, dynamic>` bundles under
  `lib/core/i18n/translations/`. **No `.arb` files.**
- Three languages: `*Uz`, `*Ru`, `*En`. **uz is the baseline.**
- Add a key:
  1. Add it to **all three** bundles (uz first).
  2. Use `tr('namespace.key')` anywhere — context-free.
- The `_missing_keys_check.dart` guard **throws at boot in debug** if ru/en
  are missing a key that uz has. A half-translated key is a boot crash, not
  a soft fallback — never ship one.
- Keys are dot-separated namespaced paths (`chat.composer_hint`,
  `search.filter.title`).
- No literal user-facing copy in widgets — always a `tr(...)`.
- The `/i18n-check` command audits bundle parity; run it after adding keys.
